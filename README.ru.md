# agent-kanban

**Локальный канбан-дашборд по вашим git-репозиториям + state-driven шаблоны работы для AI-агентов.**

[English](README.md) | Русский

Один HTML-файл показывает каждый локальный репозиторий карточкой: стадия, категория, последняя активность, коммиты, стек, незакоммиченные файлы, remote. Python-скрипт обновляет факты из git; описания, стадии и заметки — ваши. Без сети, без телеметрии, без аккаунтов.

**Требуется:** Python 3.8+, git, любой современный браузер. macOS — опционально (для запуска приложением).

## Что внутри

- `kanban/` — дашборд (один HTML-файл), updater, установщик
- `templates/` — SSOT-каркасы для агентской работы: `AGENTS.md`, `PROJECT_PLAN.md`, `TODO.md`, `CHANGELOG.md`, `WORKLOG.md`

## Установка — способ 1: CLI (любая ОС)

```bash
git clone https://github.com/HlinorAI/agent-kanban.git
cd agent-kanban
python3 kanban/kanban-init.py ~/code        # папка с вашими git-репозиториями (на глубину 1)
open ~/code/kanban.html                     # xdg-open на Linux
```

`kanban-init.py` находит репозитории, пишет `kanban-projects.json` (список репо), создаёт `kanban.html` из шаблона и заполняет факты по репозиториям.

Обновить факты в любой момент:

```bash
python3 kanban/kanban-update.py ~/code/kanban.html
```

## Установка — способ 2: приложение macOS

```bash
cd agent-kanban/kanban
./install-macos.sh --html ~/code/kanban.html                    # ставит ProjectKanban.app
./install-macos.sh --html ~/code/kanban.html --with-schedule    # + обновление при логине и ежедневно в 09:00
./uninstall-macos.sh                                            # полное удаление
```

Приложение открывает доску в отдельном окне Chrome (без адресной строки) и при каждом запуске обновляет факты в фоне — окно открывается мгновенно, свежие данные видны при следующем открытии или по ⌘R. Первый запуск: macOS один раз спросит доступ к файлам — это нужно для чтения ваших репозиториев, включая фоновые запуски по расписанию. Логи: `~/Library/Logs/kanban-app.log`.

## Обновление по расписанию без приложения (cron, Linux/macOS)

```cron
0 9 * * * cd /путь/к/agent-kanban && python3 kanban/kanban-update.py /путь/к/kanban.html >> /tmp/kanban-update.log 2>&1
```

## Как править доску

- Карточки, категории, описания: редактируйте блок `var P = [...]` в `kanban.html`.
- Всё между `/* KB-DATA-BEGIN … KB-DATA-END */` — зона updater-а: он сначала делает `.bak` и отказывается писать, если guard-и обнаружили ручные данные в зоне.
- Репозитории из `kanban-projects.json`, которых нет в `P`, получают минимальные автокарточки (`auto_register: true`) — позже дополните их описаниями.
- Перемещения по стадиям и заметки хранятся в браузере (localStorage) и в файл не пишутся.
- Связанные репозитории можно объединить в семейства (блоки `GROUP`/`G`) и показывать как один продукт.

## Агентский набор

Скопируйте `templates/*.md` в корень своего проекта и укажите агенту (Claude Code, Codex, ZCode, Cursor, …) на `AGENTS.md` — большинство инструментов подхватывают его автоматически. Цикл, который он задаёт: читать состояние проекта перед работой (файлы, а не память чата), записывать состояние после каждого значимого шага, короткая спека в `.ai/specs/` до нетривиального кода, тесты как исполняемая спека, и никогда не заявлять «фичи нет», не проверив спеки, тесты и код.

## Приватность

Только локально: читает репозитории через `git` и файловую систему, не открывает сетевых соединений, показывает remote-URL с зачисткой данных доступа.

## Известные ограничения

- Строки интерфейса в v0.1 — русские (i18n запланирован, см. TODO.md).
- Очень большие папки репозиториев сканируются медленно.
- Одностраничной доске комфортно примерно до 100 карточек.
