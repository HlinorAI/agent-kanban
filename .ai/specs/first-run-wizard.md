# Спека: First-Run Wizard (мастер первого запуска)

Дата: 2026-11-05 · Статус: v0.2 · Родитель: PROJECT_PLAN.md

## Назначение
Сценарий владельца: «поставил → при первом запуске само нашло репо → само построило канбан → само предложило включить память агентов». Один вход, прозрачные подтверждения, без записи без согласия.

## Контракты

### kanban-setup.py (CLI, интерактивный по умолчанию)
1. **Discovery**: сканирует стандартные корни (`~/Documents`, `~/Documents/Projects`, `~/Projects`, `~/code`, `~/src`, `~/dev`, `~/Developer`, `~/work` — только существующие), глубина ≤ 2, пропуск `SKIP_DIRS`; находит каталоги с `.git` (файл или каталог — worktree тоже). Дедупликация путей; собственный каталог кита и target не сканируются.
2. **Выбор**: нумерованный список найденного сгруппированно по корню; ответ по умолчанию — все. Флаги неинтерактивности: `--roots "a,b"`, `--yes` (принять всё), `--seed` / `--seed-full`, `--target DIR`.
3. **Доска**: создаётся в `--target` (по умолчанию `~/kanban/`): `kanban.html` из шаблона + `kanban-projects.json` (пути в `~/`-виде, `auto_register: true`) → запуск updater.
4. **Посев памяти агентов**: для каждого выбранного репо, где нет `AGENTS.md`, кандидат на посев. Интерактив: список «что будет записано» → подтверждение. `--seed` = только `templates/AGENTS.md`; `--seed-full` = AGENTS.md + 4 скелета SSOT. **Существующие файлы никогда не перезаписываются** — пропуск с пометкой.
5. **Финал**: сводка (доска: путь; репо: N; посеяно/пропущено) + подсказки (открыть доску; поставить app).

### ProjectKanban.app (macOS), интеграция
- Дефолтный путь доски установщика: `~/kanban/kanban.html`.
- Если доски нет при запуске app → app открывает Терминал с мастером (`macos-first-run.command`, генерируется установщиком), повторный запуск после завершения — обычное открытие доски.

## Критерии приёмки
1. Синтетическое дерево в /tmp: discovery находит все репо на глубинах 1–2, дубли исключены, `SKIP_DIRS` и чужие корни не трогает.
2. `--yes --seed --roots … --target …` отрабатывает без stdin; в каждом репо появился AGENTS.md; существующий AGENTS.md не перезаписан; повторный запуск — 0 новых записей.
3. Без флагов мастер интерактивен, дефолт-ответ — принять всё; пустой ввод не ломает.
4. Ничего не пишется вне target и выбранных репо.
5. README (EN/RU): метод 1 = мастер; init остаётся как неинтерактивный метод.
